# 🕊️ 키네틱 데이터 아트 [실시간 운영 핵심 시스템] 패키지

본 폴더(`kinetic_realtime_system`)는 **글로벌 실시간 소셜 데이터(Bluesky)를 수집하여 36개의 키네틱 막대와 3D 미디어아트 파도로 변환하고, 노트북으로 비상 원격 제어하는 전체 실시간 시스템의 핵심 파일들만 모아놓은 전용 패키지**입니다.

---

## 📂 파일 구성 및 역할 안내

### 1. 하드웨어 펌웨어 (임베디드 제어)
* 📁 **`esp32_master_gateway/esp32_master_gateway.ino`**
  * **마스터 게이트웨이 보드 (C to C / `COM15`)**에 업로드하는 펌웨어입니다.
  * 전시장 Wi-Fi에 연결되어 5초마다 Bluesky 오픈 소셜의 실시간 전쟁 언급량을 수집합니다.
  * 노트북 대시보드 서버(`http://192.168.0.20`)를 호스팅하며, 슬레이브 보드들로 **0.001초(1ms) 초고속 ESP-NOW 무선 패킷을 브로드캐스트**합니다.
* 📁 **`esp32_slave_node/esp32_slave_node.ino`**
  * **슬레이브 수신기 보드 (A to C / `COM16`)**에 업로드하는 펌웨어입니다.
  * **전시장 Wi-Fi에 접속할 필요 없이**, 마스터가 쏜 1ms 무선 신호를 즉시 수신하여 마스터와 100% 동일한 위상(`wavePhase`)으로 서보모터를 구동합니다.

---

### 2. 웹 & 3D 시뮬레이션 시스템
* 🌐 **`exhibition_visual.html`**
  * **전시장 대형 스크린용 3D WebGL 실시간 미디어아트 시뮬레이션**입니다.
  * 28,000개의 파티클과 36개 키네틱 막대+종의 물결 파도를 3D로 실시간 렌더링하며, 글로벌 소셜 데이터 긴장도에 따라 4단계 색상(샴페인 골드 ↔ 핏빛 레드)으로 변화합니다.
  * 관람객이 접근할 때 파도가 잦아드는 **'전쟁 억제력(War Deterrence)' 센서 인터랙션**을 포함합니다.
* 🕹️ **`control_dashboard.html`**
  * **노트북 무선 원격 비상 관제 대시보드**입니다.
  * 브라우저에서 버튼 클릭 한 번으로 **[전체 36개 모터 150° 긴급 정지]**, **[실시간 파도 가동]**, **[0.001초 파도 위상 정렬]**을 원격 명령합니다.
* 📑 **`team_presentation_deck.html`**
  * **스타벅스 디자인 시스템 기반 팀 최종 발표자료 슬라이드 덱**입니다.
  * 작품 컨셉, 실시간 알고리즘, 물리 기구학 수식, 인터랙티브 3D 시뮬레이션/대시보드 바로가기 링크를 담고 있습니다.
* 📦 **`art_tech_deploy.zip`**
  * Netlify/Vercel 등 무료 호스팅에 드래그 앤 드롭으로 **10초 만에 웹사이트로 배포할 수 있는 완성형 압축 패키지**입니다.
