# Usage & References (`usage/`)

이 폴더는 프로젝트에 사용되는 하드웨어 부품, 센서, 모듈, 라이브러리 등의 **설명서, 웹페이지 참고 링크, 데이터시트(Datasheet), 핀맵 및 프로토콜 정보**를 보관하는 공간입니다.

## 📁 추천 폴더 구조
```text
usage/
├── README.md               # 폴더 안내 파일
├── servos/                 # 서보 모터 관련 데이터시트 및 참고 자료
├── sensors/                # 센서 모듈 데이터시트 및 사용법
└── references.md           # 자주 참고하는 웹사이트 / 문서 링크 모음
```

## 📝 활용 가이드
- **PDF/이미지**: 부품 매뉴얼, 회로도, 데이터시트 문서를 해당 부품 분류 폴더에 저장해 둘 수 있습니다.
- **마크다운(.md)**: 각 부품별 제어 명령어, 코드 예시, 주의사항을 정리해두면 AI가 코드 작성 시 정확히 참고할 수 있습니다.
