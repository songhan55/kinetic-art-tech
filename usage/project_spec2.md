# 🕊️ 현재의 상황을 바탕으로 가까운 미래를 예측하는 장치
## (Device for Predicting the Near Future Based on the Present Situation)
### [v2.5] ESP32 마스터 게이트웨이 & 4대 슬레이브 분산 무선 제어 시스템 공식 전시 명세서

## 1. 프로젝트 개요 및 컨셉 (Concept & Philosophy)

본 작품은 **"현재의 실시간 글로벌 빅데이터와 오픈 소셜 미디어의 전쟁·분쟁 언급량을 실시간 수집하여, 가까운 미래의 전쟁 위험도를 수십 개의 키네틱 종 파도와 3D 미디어아트로 가시화하고, 관람객의 물리적 접근을 통해 '전쟁 억제력(War Deterrence)'을 증명하는 감응형 인터랙티브 키네틱 미디어아트"**입니다.

1. **실시간 트렌드 데이터 수집**: **ESP32 마스터 게이트웨이**가 오픈 소셜 미디어의 글로벌 7대 분쟁 키워드(`#war`, `#conflict`, `#ukraine`, `#iran`, `#missile`, `#military`, `#crisis`)의 실시간 긴장도 지수($S(t)$)를 수집합니다.
2. **미래 위험도 예측의 시·청각화**: 1.0m 캔틸레버 유리섬유 막대와 끝단에 장착된 황동 종들이 실시간 위기 점수에 비례하여 격렬하게 물결치며 전시장 전체에 경각심의 소리를 울립니다.
3. **전쟁 억제력(War Deterrence) 인터랙션**: 관람객이 비극의 현실에 관심을 가지고 다가설수록, **마스터 보드에 장착된 3채널 초음파 센서 감응**을 통해 모터 파도와 3D 미디어아트 영상이 잔잔한 평화의 침묵(150° 수직 정렬 홈 포지션)으로 실시간 정화됩니다.

## 2. 공간 레이아웃 및 기구부 물리적 사양

* **전시 공간**: **한 변이 2.5m인 정삼각형(Equilateral Triangle) 바닥 영역**
* **모터 축 배치 방향**: **바닥(지면)과 평행하게 횡방향(Horizontal) 설치**
* **물리적 매체 (동적 캔틸레버)**:
  * 직경 2.5mm, **길이 1.0m 유리섬유 로드(Fiberglass Rod)** (총 36~48개)
  * 로드 팁(끝단): **30g 소형 황동 종 (Small Brass Bell)** 장착
* **서보 모터 사양**:
  * **MG996R 메탈기어 고토크 서보 모터** (총 48개 구동 가능 구조)
* **모터 기준 각도 및 구동 범위**:
  * **기준 중립 홈 각도**: **`150.0°`** (수직 정렬 홈 포지션)
  * **모터 스윙 허용 범위**: **`115.0° ~ 185.0°`** (기본 진폭 `±5.0° ~ ±20.0°`, 커스텀 최대 `±35.0°`)

## 3. 분산 무선 임베디드 네트워크 아키텍처 (ESP-NOW Multi-Slave)

```text
[ 관람객 물리적 접근 ] ── (0.3m~2.0m 거리) ──> [ 📡 HC-SR04 초음파 센서 3채널 ]
                                                        │
                                                        ▼
[ 🌐 글로벌 실시간 분쟁 지수 S(t) ] ──────> [ 🟢 Master Gateway ESP32 (COM17) ]
                                                        │
                                ⚡ ESP-NOW 0.001초(1ms) MAC 직결 무선 브로드캐스트
                                ┌───────────────────────┴───────────────────────┐
                                ▼                                               ▼
                [ 🟣 Slave Node #1 ~ #4 ESP32 ]                 [ 💻 관제 대시보드 & 3D 비주얼 ]
                                │                                               │
                                ▼                                               ▼
                [ PCA9685 16채널 × 4대 (총 48개 서보) ]            [ 119,600개 파티클 등고선 붕괴/정화 ]
                * 150° 기준 칼군무 소셜 파도 스윙                 * Collapsing Noise 3D WebGL 실시간 렌더링
```

### 1) 마스터 게이트웨이 (Master Gateway ESP32)
* **포트 / MAC 주소**: `COM17` / `30:76:F5:30:2E:0C` (IP: `192.168.0.14` 고정)
* **3채널 초음파 센서 실시간 융합**: 전방 3개 구역의 관람객 거리를 60ms 주기로 병렬 측정 후 유효 거리 $D$ 및 감쇄 계수 $K$ 산출.
* **초고속 50Hz ESP-NOW 브로드캐스트**: Wi-Fi 공유기 트래픽 간섭 없이, 슬레이브 4대로 0.001초(1ms) 단위 무선 패킷(점수, 위상, 감쇄율 $K$) 송출.
* **내장 웹서버 & 브리지 서버**: 80포트 내장 웹서버 및 로컬 8000포트 브리지를 통해 관제 대시보드로 텔레메트리 30fps 실시간 전송.

### 2) 4대 슬레이브 노드 (Slave Nodes #1 ~ #4)
* **등록된 고유 MAC 주소**:
  * **Slave #1**: `8C:94:DF:6D:8B:C4` (PCA9685 #1 드라이버, 12~16채널 서보)
  * **Slave #2**: `8C:94:DF:6D:F5:34` (PCA9685 #2 드라이버, 12~16채널 서보)
  * **Slave #3**: `8C:94:DF:B9:AD:30` (PCA9685 #3 드라이버, 12~16채널 서보)
  * **Slave #4**: `B8:D6:1A:65:EA:60` (PCA9685 #4 드라이버, 12~16채널 서보)
* **1ms 칼동기화 구동**: 마스터의 무선 패킷 수신 즉시 슬레이브 전체가 0.001초 오차 없이 동일한 위상 곡선($\text{Phase}$)에 맞춰 부드러운 사인파 군무 파도 형성.
* **전원 분리 설계**: 로직 전원(3.3V)과 서보 전용 고전류 파워서플라이(5V 20A+)를 분리하여 브라운아웃 완전 방지.

## 5. 초음파 센서 감쇄 수학 모델 (Deterrence Damping Curve)

초음파 센서 3채널의 계측값을 취합하여 유효 최소 거리를 산출하고, 지수 평활 필터($\alpha=0.15$)를 거쳐 감쇄 계수 $K(D)$를 산출합니다.

```text
    [ 관람객 거리 D ]                      [ 감쇄 계수 K(D) ]              [ 키네틱 모터 & 3D 비주얼 반응 ]
 ─────────────────────────────────────────────────────────────────────────────────────────────
  원거리 (D ≥ 2.0m)       ──>  K = 1.00 (감쇄율 0%)   ──>  날것의 실시간 분쟁 데이터 100% 반영 (격렬한 파도 & 붉은빛)
  접근 중 (0.3m ≤ D < 2.0m) ──>  K = 0.15 + ((D-0.3)/1.7)*0.85 ──>  관심과 개입에 의한 실시간 파도 진정 (골드/그린 전환)
  초근접 (D < 0.3m)       ──>  K = 0.15 (감쇄율 85%)  ──>  완전한 평화 침묵 (±5° 잔잔한 미세 스윙 & 은은한 화이트)
```

* **수학적 공식**:
  $$K(D) = \begin{cases} 
  1.00 & (D \ge 2.0\text{m}) \\
  0.15 + \left(\dfrac{D - 0.3}{1.7}\right) \times 0.85 & (0.3\text{m} \le D < 2.0\text{m}) \\
  0.15 & (D < 0.3\text{m})
  \end{cases}$$

## 7. 전시장 3D 미디어아트 비주얼 시스템 (Collapsing Noise WebGL)

119,600개 GPU 파티클(260 등고선 × 460 정점)로 구성된 3D WebGL 실시간 렌더링 시스템입니다.

### 1) 4대 핵심 물리 파라미터 제어 공식 ($D_{eff} = D \times K$)
* **`noiseSpeed`**: $0.60 + (D_{eff} \times 0.90)$ (시간 방향 노이즈 변형 속도)
* **`noiseAmp`**: $0.35 + (D_{eff} \times 0.45)$ (3D 공간 지형 왜곡 및 단열 주름 강도)
* **`suction`**: $0.25 + (D_{eff} \times 0.55)$ (중심부 구심력 붕괴 응집 에너지)
* **`rotation`**: $0.15 + (\text{유입 글 수} / 10) \times 0.20$ (화면 수직축 우아한 자전 흐름)
